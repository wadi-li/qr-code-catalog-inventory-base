# Каталог предметов 2.0 — Android-приложение и веб-версия

Учёт вещей и оборудования по коду с четырёхуровневым каталогом:
**Тип → Группа → Подгруппа → Название → Комментарий**. Код (серийный номер, штрих-код,
QR) — первое поле и ключ записи. Дата и время создания подставляются автоматически,
но их можно изменить вручную.

## Состав поставки

| Файл | Что это |
|---|---|
| `android/` | Исходники Android-приложения (Kotlin, Gradle) |
| `web/index.html` | Веб-версия для компьютера: один автономный файл, интернет не нужен |
| `release/KatalogPredmetov-2.0.apk` | Готовое приложение для Android 7.0+ (подписанный релиз, 27 МБ) |

---

## 1. Установка Android-приложения

1. Скопируйте `KatalogPredmetov-2.0.apk` на телефон.
2. Откройте файл, разрешите «Установка из этого источника» (Настройки → Приложения →
   Специальный доступ → Установка неизвестных приложений).
3. При первом запуске сканера разрешите доступ к камере, а для уведомлений об архиве —
   разрешение на уведомления (Android 13+ спрашивает отдельно).

Пакет: `ru.vdl.catalog`, версия 2.0 (versionCode 2). Подпись: SHA-256
`0fa397ed497146e9d46d1e60338e2e8d5abafd52f7a0be604c7a74bed06856be`.

### Что внутри
- **Сканер** (кнопка «Сканировать»): распознаёт CODE-128/39/93, CODABAR, EAN-13/8,
  UPC-A/E, ITF, QR, DataMatrix, PDF417, Aztec. Работает **офлайн** — модель распознавания
  вшита в APK (отсюда и размер). Есть фонарик и кнопка «Ввести вручную».
- **Предиктивный ввод**: все введённые значения Типа, Группы, Подгруппы, Названия и
  Комментария запоминаются и предлагаются при следующем вводе; подсказки для Группы
  фильтруются по выбранному Типу, для Подгруппы — по Типу и Группе.
- **Поиск**: одно поле, поиск по коду, названию, комментарию и категориям, несколько слов
  через пробел (все слова должны найтись). Плюс фильтры по Типу и Группе и сортировка по
  дате, коду, названию или пути каталога.
- **Повтор кода**: если введённый код уже есть в базе, открывается существующая карточка —
  дублей не будет (код уникален).
- **Плановая архивация**: период задаётся в настройках (1, 6, 12, 24, 72, 168, 336, 720 часов
  или своё число; 0 — выключено). Архив — ZIP с `catalog-*.json` и `catalog-*.csv`, лежит
  внутри приложения, хранится N последних копий (по умолчанию 10).
- **Отправка на e-mail**: два пути — автоматически по SMTP (см. ниже) и вручную через
  «Отправить через почтовый клиент» (архив прикладывается через системное «Поделиться»).
- **Тема**: «Как на устройстве» / «Светлая» / «Тёмная».

### Настройка отправки по SMTP
Настройки → «Отправка архива на e-mail (SMTP)». Нужны: сервер, порт, логин, пароль,
адрес отправителя и получателя.

| Почта | Сервер | Порт | Режим | Пароль |
|---|---|---|---|---|
| Яндекс | `smtp.yandex.ru` | 465 | SSL | пароль приложения в Яндекс ID |
| Gmail | `smtp.gmail.com` | 465 | SSL | App password (при включённой 2FA) |
| Gmail (альтернатива) | `smtp.gmail.com` | 587 | STARTTLS | App password |
| Mail.ru | `smtp.mail.ru` | 465 | SSL | пароль для внешних приложений |

Обычный пароль от аккаунта не подойдёт — нужен именно пароль приложения. Проверить
настройки можно кнопкой «Создать архив и отправить сейчас»: результат покажется в
строке состояния.

### Про точность расписания
Android сам решает, когда запустить фоновую задачу: при экономии заряда или в режиме
«Не беспокоить» архив может создаться позже назначенного часа (обычно в пределах часа,
минимальный период системы — 15 минут). Чтобы задержки были минимальными, отключите
оптимизацию батареи для приложения: Настройки → Приложения → Каталог предметов →
Батарея → «Без ограничений».

## 2. Веб-версия для компьютера

Откройте `web/index.html` двойным щелчком в любом браузере. Один файл, никаких
установок и интернета: библиотека распознавания QR вшита внутрь. Данные лежат в
localStorage этого браузера в этом профиле, поэтому **регулярно делайте архив**.

Возможности: та же карточка и тот же поиск с подсветкой совпадений, сортировка по щелчку
на заголовке таблицы, фильтры, предиктивный ввод через списки подсказок, светлая/тёмная/
системная тема, скачивание архива (ZIP: JSON+CSV, либо только JSON, либо только CSV),
восстановление из файла (объединить или заменить базу), плановая архивация по часам.

Что браузер физически не умеет:
- работать по расписанию, когда страница закрыта — проверка расписания срабатывает при
  открытии страницы и далее каждые 5 минут, пока она открыта;
- подключаться к SMTP напрямую. Поэтому автоматическая отправка сделана через EmailJS
  (свободный аккаунт, шаблон с параметрами `{{record_count}}`, `{{exported_at}}`,
  `{{backup_json}}`), а вариант «Почтовый клиент» открывает готовое письмо в вашей
  почтовой программе, куда нужно вручную приложить только что скачанный файл архива.
  Полностью автономная отправка с вложением — в Android-приложении.

Старые данные из прежней программы подхватываются автоматически: если в этом браузере
остались записи из старой версии (ключ `inv_records`), они переносятся при первом
открытии, причём старое поле «Группа» попадает в **Подгруппу**, а Тип и Группа остаются
пустыми — заполните их по мере правки карточек.

## 3. Обмен данными между телефоном и компьютером

Формат JSON одинаковый (`"format": "catalog-v2"`), поэтому:
- архив из телефона (`catalog-*.json` или ZIP) восстанавливается в веб-версии кнопкой
  «Восстановить из файла»;
- архив из веб-версии открывается в приложении: меню → «Восстановить из JSON».

При восстановлении спрашивается режим: объединить (обновление по коду + добавление
новых) или заменить базу целиком.

CSV: разделитель `;`, UTF-8 с BOM, кавычки удвоены, перевод строки CRLF — Excel
открывает двойным щелчком без «Мастера импорта».

## 4. Сборка и обновления

Релизный APK подписывается вашим ключом `catalog-release.jks`. Ключ и пароли в
репозиторий не входят (см. `.gitignore`) — храните их отдельно: без этого ключа
обновление не установится поверх старой версии.

Сборка (нужны JDK 17 и Android SDK 35, Gradle скачается через wrapper):

```
cd android
cp keystore.properties.example keystore.properties   # указать путь к ключу и пароли
./gradlew assembleRelease
```

Вместо файла можно передать переменные окружения `KS_FILE`, `KS_PASS`, `KS_ALIAS`,
`KS_KEYPASS`. Без настроек подписи собирается неподписанный релиз, а `./gradlew
assembleDebug` — отладочная версия. Готовый файл — в `app/build/outputs/apk/`.
Перед выпуском поднимайте `versionCode` и `versionName` в `app/build.gradle.kts`.

GitHub Actions (`.github/workflows/android.yml`) собирает debug APK при каждом push в `main`.

## 5. Проверено при сборке

- APK собран и подписан, подпись проверена `apksigner verify`; статический анализ
  (`lint`) проходит без ошибок.
- Веб-версия прогнана в браузере: добавление карточек, автоподстановка даты, повтор
  кода (карточка открывается на правку, дублей нет), поиск по коду, названию,
  комментарию и категориям с подсветкой, фильтры, сортировка по всем колонкам,
  скачивание ZIP (проверена целостность архива и содержимое JSON/CSV), восстановление
  из файла старого формата, сохранение данных и темы после перезагрузки страницы,
  светлая и тёмная темы — ошибок в консоли нет.
- Запустить приложение на эмуляторе в этой среде было нельзя (нет аппаратной
  виртуализации), поэтому поведение на живом телефоне — сканер, уведомления, SMTP —
  проверьте, пожалуйста, сами и напишите, что поправить.
